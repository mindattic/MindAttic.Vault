# /deploy -- no web deploy

**MindAttic.Vault has no web deploy.** Its README on GitHub -- https://github.com/mindattic/MindAttic.Vault -- is the project page. To update the project page, edit `README.md` and push to `main`.

MindAttic.Deploy does not build a page for this project (`npm run deploy -- --only mindatticvault` is rejected), so do not run MindAttic.Deploy for this project.

When invoked, tell the user the above and stop.
